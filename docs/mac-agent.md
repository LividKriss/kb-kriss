# Mac attachment agent — instructions (part C of the daily email run)

Runs **Claude Code headless on Kriss's Mac, every hour while the Mac is awake** (launchd job `no.livid.kb-kriss-mac-agent`, `claude -p "Follow docs/mac-agent.md in ~/kb-kriss"`). Exists because the cloud Gmail connector can't read attachments; on the Mac, the Gmail API (token in the Keychain, scopes readonly + modify + send) can.

## Each run
0. If a Gmail draft with subject `[STOP-SENDING]` exists, forward nothing this run (send policy kill switch); still file customs and read documents.
1. Read `~/kb-kriss/AGENTS.md`, `~/livid-kb/AGENTS.md`, livid-kb `finance/bookkeeping/processes/invoice-routing.md` (follow it exactly), and the supplier Organization docs it needs (`kb_find.py`).
2. **Invoices:** messages labelled `AI/Invoice` (set by the 06:47 cloud run) and any new unlabelled mail with a PDF from a supplier domain or to invoice@ since the last run. Download the PDFs (`scripts/email/gmail_tool.py`), read them, then per invoice-routing:
   - clear case (step 6) → forward to the entity's PowerOffice voucher address, label `AI/PO-forwarded`, remove `AI/Invoice`;
   - external brand (step 7b) → also forward to Ole Eivind with the Norwegian note + auto-sent disclaimer;
   - addressed to Livid Jeans Unipessoal (step 7c) → Livid Jeans AS's voucher address unless already paid against a proforma (check, don't guess; unclear → brief), and every official invoice/credit note (not proformas) to Patrícia at HK Consulting (`pfaisca@hkconsulting.pt`) with the English note + auto-sent disclaimer (an `.html` note like Ole Eivind's);
   - once every forward for a message is done and labelled: `gmail_tool.py archive <msg_id>` (archives the thread; the tool keeps it in the inbox while it carries `AI/Urgent`, `AI/Reply`, `AI/Action`, `AI/HR`, `AI/Invoice`, `AI/Payments`, `AI/Docs` or `AI/Docs-read`) — `kb/email/actions.md`: after sending, archive;
   - not clear → keep `AI/Invoice`, and add a one-line reason to the message's entry in the run log so the brief can show "why not automatic".
3. **Documents and links (`AI/Docs`):** threads the cloud run marked because the email points to a document or link that matters (packing list, proforma, PO, production plan, shipping or customs papers, contract, price list). New unlabelled supplier/production mail found in step 2 that carries such documents (and isn't a voucher to forward) → label the thread `AI/Docs` yourself and handle it in this run, so documents that arrive after the morning run don't wait a day. For each, newest first:
   - Download attachments (PDF, Excel, Word, images) and open links that work without a login (WeTransfer, public Drive/Dropbox). A link behind a login → note "link needs login", don't try to sign in.
   - Store them in `~/Library/Application Support/kb-kriss/docs/<threadId>/` (never in a repo).
   - Read them and write a **Gmail draft, no recipient, subject `[Doc] <thread subject>`**: 3–8 lines of facts that matter for a decision (what the document is, PO/order numbers, quantities, cartons, dates/ETD/ETA, amounts, discrepancies vs. what was agreed, what it asks of Kriss), plus the Gmail thread link. The morning brief reads these.
   - Durable facts → the KB per `kb/email/kb-sync.md`: Person note history/open threads directly; company facts (supplier terms, lead times, routes) as a "Proposed for Livid KB" line in the `[Doc]` draft, for Kriss to confirm in the brief.
   - Relabel the thread `AI/Docs` → `AI/Docs-read`.
   Skip logos, signatures, newsletters, and anything HR/private (AGENTS.md §2).
4. **Customs:** run `scripts/email/file_customs.py` (it files `AI/Customs` mail into Tolldeklarasjoner/LJAS|LRAS and relabels `AI/Filed`, then archives the thread unless it still needs Kriss).
5. **Housekeeping:** delete folders in `…/kb-kriss/docs/` older than 14 days, and `[Doc]` drafts whose thread is archived or older than 14 days.
6. **Log:** append one line per run to `~/Library/Logs/kb-kriss-mac-agent.log` and, if anything was forwarded or filed, one `kb/log.md` entry (counts, suppliers, entity; no amounts or bodies). Auto-sync pushes it; the morning brief reads it for "Forwarded automatically".
7. Never: reply, delete, unsubscribe, or send to anyone other than the two PowerOffice voucher addresses, Ole Eivind (`oleeivind@livid.no`) and Patrícia at HK Consulting (`pfaisca@hkconsulting.pt`). Never forward the same message twice (`AI/PO-forwarded` and the Sent check). Raw mail and PDFs only in a temp folder outside the repo, deleted at the end of the run.

## Setup (Claude Code, once)
- Gmail scopes in `scripts/email/gmail_auth.py`: readonly + modify + send; re-authorize.
- Python packages in the venv: pypdf, openpyxl, python-docx.
- `scripts/email/gmail_tool.py`: small CLI over `gmail_service()` — `list <query>` (JSON lines), `attachments <msg_id> <dir>` (download all attachments), `fetch <url> <dir>` (public links only: WeTransfer, Drive/Docs, Dropbox, direct files; exit 4 = page or login, nothing saved), `draft <threadId> <subject> <body-file>` (replaces an earlier [Doc] draft for that thread) / `drafts` / `delete-draft <id>` (only [Doc] drafts) / `housekeep` (step 5), `text <file>` (PDF, Excel, Word, CSV), `forward <msg_id> <to> [--note file] [--only NAME …]` (forwards the message's PDFs, or only the named voucher PDFs; note above the quoted message, Kriss's Gmail signature after it), `label <msg_id> +A -B`. The recipient allowlist and the duplicate checks (label, Sent in the thread, same file name in Sent) are in the code; exit 3 = skipped as already forwarded. The note for Ole Eivind is an `.html` file in the run's temp folder: the 7b text, then the auto-sent disclaimer from `kb/email/signature.md` in its grey `<p>`.
- `scripts/email/mac_agent.sh [--dry]`: one run. Makes the per-run temp folder (deleted afterwards), passes the last-run time, runs `claude -p` in `dontAsk` mode with only: Read/Glob/Grep, WebFetch (reading public pages), the two scripts, `kb_find.py`, `build_index.py`/`validate.py`, edits to `kb/log.md` (+ `kb/index.md`), `kb/people/` and the temp folder. `--dry` sets `KB_AGENT_DRY=1`, which makes `forward`, `label`, `draft`, `delete-draft`, `housekeep` and `file_customs.py` print instead of act, and allows no repo edits.
- `scripts/email/install_mac_agent.sh`: launchd job `no.livid.kb-kriss-mac-agent`, hourly (`StartInterval 3600`, `RunAtLoad`), log `~/Library/Logs/kb-kriss-mac-agent.log`. Needs the standalone `claude` CLI, logged in. Replaces `install_customs_job.sh` (removes that job if present). Install only after a dry run looked right.
